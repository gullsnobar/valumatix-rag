# Tarnwick Client Project Delivery Process

Version 1.3 - Effective 1 January 2026 - Owner: Head of Delivery

## 1. Phases
| Phase | Typical length | Main output |
| --- | --- | --- |
| Discovery | 1 to 2 weeks | Requirements and solution outline |
| Design | 1 to 2 weeks | Approved solution design |
| Build | 2 to 6 weeks | Configured system and automations |
| User Acceptance Testing (UAT) | 1 week | Client sign-off |
| Handover | 1 week | Documentation and training |

## 2. Status Reporting
Project managers send a written status report to the client every Friday, covering progress, risks and next steps.

## 3. Change Requests
Any change to agreed scope needs a written change request with its effect on cost and timeline. Work on a change starts only after the client approves it in writing.

## 4. Acceptance
The client has 5 working days after UAT to accept the delivery or list defects. If no response arrives in that time, the delivery is treated as accepted.

## 5. Post-Launch Support
Every project includes 30 days of post-launch support for defects at no extra cost.
